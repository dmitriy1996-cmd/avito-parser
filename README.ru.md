# Устойчивый парсер Avito.ru на Node.js

Многопоточный, отказоустойчивый веб-скрейпер для [Avito.ru](https://www.avito.ru) на
**Playwright + stealth**, с ротацией **резидентных прокси** и имитацией
**поведения человека** для обхода антибот-защит и фингерпринтинга.

> Материал опубликован в образовательных целях. Используйте парсер только в рамках
> законодательства РФ, Пользовательского соглашения Avito и файла `robots.txt`.

## Возможности

- **Stealth**: `playwright-extra` + `puppeteer-extra-plugin-stealth` плюс ручное
  усиление через init-скрипты (`navigator.webdriver`, `languages`, `plugins`, WebGL,
  `permissions`).
- **Параллелизм**: `p-limit` запускает N изолированных **контекстов браузера**
  одновременно (по умолчанию 5) — это намного легче по CPU/RAM, чем поднимать
  отдельные браузеры.
- **Уникальная личность для каждого контекста**: свой User-Agent, разрешение экрана,
  часовой пояс и **липкая сессия ротационного прокси** — у каждого контекста свой
  выходной IP.
- **SOCKS5 и HTTP прокси**: HTTP/HTTPS используются нативно; **SOCKS5 с авторизацией**
  работает через автоматически поднимаемый локальный мост HTTP→SOCKS (`proxy-chain`),
  потому что Chromium сам не умеет авторизацию в SOCKS.
- **Поведение человека**: плавное движение курсора по кривой, неравномерный скролл
  с возвратами, случайные паузы 2000–6000 мс перед действиями.
- **Отказоустойчивость**: до 3 повторов с джиттер-бэкоффом при таймаутах / 403 / 429 /
  падении прокси; каждый повтор — новая сессия прокси и новая личность.
- **Решение капчи**: распознаёт фаервол-капчу Avito (hCaptcha, «Доступ ограничен:
  проблема с IP») и решает её автоматически через **2Captcha** при заданном
  `TWOCAPTCHA_API_KEY`; иначе аккуратно логирует и идёт дальше без падения процесса.
- **Структурированный вывод**: пишет `results.json` с данными по каждому объявлению и
  сводкой по запуску, а также `results.csv` — таблицу (UTF-8 + BOM, разделитель `;`),
  которая корректно открывается в Excel / Google Таблицах.

## Какие поля извлекаются

`title` (заголовок), `price` (цена), `description` (описание), `sellerName` (продавец),
`sellerType` (компания/частное лицо), `sellerUrl` (ссылка на профиль),
`location` (адрес/город), `images[]` (URL фото в высоком разрешении), `phone`
(телефон, best-effort).

> **Телефон:** Avito прячет номер за кнопкой «Показать телефон», которая для
> гостей открывает **окно входа**. Поэтому `phone = null`, если не запускать
> парсер с авторизованной сессией Avito (куки аккаунта). См. ниже.

```

## ⚠️ Важно: для Avito запускайте в HEADFUL-режиме

Avito-фаервол **блокирует headless Chromium** (отдаёт капчу «Доступ ограничен:
проблема с IP»), но пропускает **headful** (видимое окно) в связке с российским
резидентным прокси и stealth.

Проверенная рабочая конфигурация:

- `HEADLESS=false` (обязательно)
- **Российский** резидентный прокси (например, NodeMaven `-country-ru`)
- Включённые ретраи — редкий помеченный IP повторяется на новой сессии

С этим реальные карточки парсятся со статусом 200 и всеми полями. Хук 2Captcha
оставлен как резервный, но капча Avito — это hCaptcha Enterprise (нужен
`rqdata`); на практике именно повтор на свежем IP в headful-режиме надёжно
снимает блок. Можно оставить `TWOCAPTCHA_API_KEY` пустым и полагаться только на
headful + RU-прокси + ретраи (быстрее).

> На headless-сервере запускайте через виртуальный дисплей (`xvfb-run`), т.к.
> headful требует наличия дисплея.

## Настройка прокси

Парсер рассчитан на резидентные прокси [NodeMaven](https://nodemaven.com). Для
Avito нужен **российский** выходной IP — опция NodeMaven `-country-ru` даёт его
со sticky-сессиями, что как раз и требуется.

### Файл с прокси (рекомендуется для нескольких потоков)

Прокси задаются в **отдельном файле `proxies.txt`** — по одному в строке. Это
самый удобный способ скормить много прокси для параллельных потоков: каждый
поток берёт прокси по кругу, а уникальный id сессии подставляется
автоматически, поэтому каждый контекст получает свой sticky российский IP.

```bash
cp proxies.example.txt proxies.txt   # затем отредактируйте proxies.txt
```

```text
# proxies.txt — по одному в строке, можно комментарии через '#'
socks5://USER-country-ru-sid-AAAA-filter-high:PASS@gate.nodemaven.com:1080
socks5://USER-country-ru-sid-BBBB-filter-high:PASS@gate.nodemaven.com:1080
socks5://USER-country-ru-sid-CCCC-filter-high:PASS@gate.nodemaven.com:1080
```

У NodeMaven SOCKS5 на порту `1080`, id сессии лежит внутри username
(`-sid-<id>-`). Поставьте `SESSION_TOKEN=-sid-` в `.env`, чтобы менеджер менял
сессию на каждый контекст. Число параллельных потоков задаётся параметром
`CONCURRENCY` в `.env`.

Скрейпер сам определит схему `socks5://` и поднимет локальный мост HTTP→SOCKS
на каждый контекст (Chromium не умеет авторизацию SOCKS напрямую). Файл
`proxies.txt` в `.gitignore` — ваши креды не попадут в репозиторий.

Путь к файлу настраивается через `PROXY_FILE`. Как альтернатива — можно задать
`PROXY_LIST` прямо в `.env` (через запятую/с новой строки) вместо файла.

> Нет аккаунта? Резидентные прокси можно взять на
> [nodemaven.com](https://nodemaven.com).

### Решение капчи Avito (2Captcha)

Avito-фаервол выдаёт hCaptcha («Доступ ограничен: проблема с IP»). Чтобы решать её
автоматически, задайте ключ 2Captcha:

```env
TWOCAPTCHA_API_KEY=ваш_ключ_2captcha
```

Тогда скрейпер сам нажимает «Продолжить», решает hCaptcha через 2Captcha, подставляет
токен (через `sethCaptchaResponse` самого Avito) и продолжает парсинг. Без ключа —
просто логирует блок и идёт дальше.

## Запуск

Добавьте ссылки в `urls.txt` (по одной на строку), затем:

```bash
npm start
```

Либо передайте URL прямо в аргументах:

```bash
node src/index.js "https://www.avito.ru/.../item_123" "https://www.avito.ru/.../item_456"
```

### Поиск по ключевому запросу (без ссылок)

Можно парсить **по ключевому слову**, а не по ссылкам. Avito-поиск требует
**категорию** в пути, поэтому укажите slug категории:

```bash
node src/index.js --search "игровой ноутбук" --category noutbuki --region all --max 30 --pages 3
```

| Флаг | Env | По умолч. | Значение |
| --- | --- | --- | --- |
| `--search` / `-q` | `SEARCH_QUERY` | — | ключевой запрос |
| `--category` / `-c` | `SEARCH_CATEGORY` | `noutbuki` | slug категории (можно несколько через запятую) |
| `--region` / `-r` | `SEARCH_REGION` | `all` | регион (`all`, `moskva`, `sankt-peterburg`, …) |
| `--max` | `MAX_ITEMS` | 50 | сколько объявлений собрать |
| `--pages` | `MAX_PAGES` | 5 | сколько страниц выдачи на категорию |

Парсер строит `https://www.avito.ru/<регион>/<категория>?q=<запрос>&p=<n>`,
собирает ссылки на объявления по страницам (и категориям), затем парсит каждое.
Для поиска сразу по нескольким: `--category "noutbuki,telefony"`.

Частые slug-и категорий (также в `src/search.js` → `COMMON_CATEGORIES`):

```
avtomobili            telefony              noutbuki
planshety_i_elektronnye_knigi               tovary_dlya_kompyutera
audio_i_video         kvartiry              doma_dachi_kottedzhi
bytovaya_tehnika      mebel_i_interer       odezhda_obuv_aksessuary
tovary_dlya_detey_i_igrushki                velosipedy
instrumenty           predlozheniya_uslug
```

Результат пишется в `results.json` (а также в `results.csv` — та же выборка
в табличном виде для Excel/Google Таблиц):

```json
{
  "meta": { "total": 2, "succeeded": 2, "failed": 0, "durationMs": 18342 },
  "results": [
    {
      "success": true,
      "url": "https://www.avito.ru/...",
      "title": "iPhone 15 Pro Max 256GB",
      "price": "120 000 ₽",
      "description": "...",
      "sellerName": "Иван",
      "location": "Москва, м. Арбатская",
      "images": ["https://...jpg", "..."],
      "scrapedAt": "2026-06-27T13:00:00.000Z"
    }
  ]
}
```

## Параметры (`.env`)

| Переменная       | По умолчанию | Описание                                       |
| ---------------- | ------------ | ---------------------------------------------- |
| `CONCURRENCY`    | 5            | Параллельные контексты браузера                |
| `MAX_RETRIES`    | 3            | Число повторов на один URL                     |
| `HEADLESS`       | true         | Без окна (поставьте `false`, чтобы наблюдать)  |
| `NAV_TIMEOUT_MS` | 60000        | Таймаут навигации                              |
| `MIN_DELAY_MS`   | 2000         | Минимальная «человеческая» пауза               |
| `MAX_DELAY_MS`   | 6000         | Максимальная «человеческая» пауза              |
| `OUTPUT_FILE`    | results.json | Путь к файлу результата                        |

## Как это работает (кратко)

1. `index.js` собирает список URL (из аргументов или `urls.txt`) и через `p-limit`
   запускает не более N задач параллельно.
2. Для каждой задачи создаётся изолированный контекст с уникальными UA, viewport,
   часовым поясом и сессией прокси.
3. `scraper.js` открывает страницу, имитирует поведение человека, проверяет страницу
   на блокировку, ждёт появления контента и парсит поля.
4. При ошибке/блокировке срабатывает механизм повторов с новой личностью; после
   исчерпания попыток объявление помечается как `failed`, и процесс идёт дальше.
5. Все результаты агрегируются и сохраняются в `results.json`.

## Важные замечания

- Разметка Avito часто меняется — селекторы в `src/scraper.js` используют стабильные
  атрибуты `data-marker`, но при `null` в полях их нужно обновить.
- Без качественных **резидентных** прокси Avito отдаёт `429`/блокировку почти сразу —
  дата-центровые IP не подходят.
- Держите низкий параллелизм и щедрые задержки, уважайте правила площадки.
